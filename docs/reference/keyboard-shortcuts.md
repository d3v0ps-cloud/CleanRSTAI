# Keyboard shortcuts

Use **⌘** on macOS and **Ctrl** on Linux and Windows.

| Shortcut | Action |
|---|---|
| Enter / Shift+Enter | Send / new line (can be swapped in [General](../settings/general.html#sending)) |
| ⌘/Ctrl + Enter | Send |
| ⌘/Ctrl + N | New chat |
| ⌘/Ctrl + K | Command palette: switch model or provider, open a chat, change theme, export… |
| ⌘/Ctrl + B | Show or hide the sidebar |
| ⌘/Ctrl + [ / ⌘/Ctrl + ] | Back / forward through the chats and pages you opened |
| / (at the start of the message box) | List the slash commands and skills that match what you type |
| ⌘/Ctrl + , | Settings |
| ⌘/Ctrl + Shift + M | Start or stop a voice recording, which is transcribed into the message box (when voice input is on in [Voice](../settings/voice.html)) |
| ⌘/Ctrl + Shift + S | Read the chat's latest reply aloud, or stop the reading (when reading replies aloud is on) |
| Esc | Close settings when there are no unsaved changes; close the sidebar's search box |
| Tab / Shift+Tab | Move between controls: the message box and its buttons, the conversation, the sidebar and the title row. The focused control gets an accent-coloured outline |
| Space or Enter | Press the focused button |

In the browser view of [remote access](../using/remote-access.html), Enter and Shift+Enter follow
the Sending setting, and Esc stops a reply. The browser supports the shortcuts listed on this
page where the browser allows them.

The message box has the focus when the app opens and after you send. Tab moves out of it
(Shift+Enter makes a new line), and clicking anywhere hides the focus outline again.

All text colours meet WCAG AA contrast (4.5:1) in both themes; a test keeps them there. (The
design's placeholder grey is a little lighter than the darkest suggested, for that reason.)
**Reduce motion** in [Appearance](../settings/appearance.html) turns off fades, the sliding sidebar
and the zoom of Settings.
