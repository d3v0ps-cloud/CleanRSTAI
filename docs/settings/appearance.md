# Appearance
{: .no_toc }

Theme, size, motion, your name, and how replies look. Each setting is one row, with its control
on the right. **Design** in the sidebar opens this page.

1. TOC
{:toc}

## Theme

Three icons: **Dark**, **Light** and **Match the system** (default), which follows your
operating system. You can also switch from the command palette.

## UI scale

Scales the whole window, text included: 80%, 90%, 100% (default), 110%, 125%, 150%, 175% or 200%.

## Your name

The name in the greeting on a new chat and in the sidebar's footer. Empty (default) uses your
account's user name, from its first part (`aaron.b` greets *Aaron*).

## Reduce motion

Off by default. On: no hover fades, the sidebar shows and hides at once instead of sliding, and
Settings opens without fading and zooming in.

## Reasoning

How a reasoning model's **Thought process** section starts out:

- **Collapsed** (default)
- **Expanded**
- **Expanded while thinking**: open while the model reasons, collapsed once it answers.

## Speed stats

Prefill/decode speed and token counts under responses (default on).

## Load web images in replies

Off by default. When off, images from the web show as links. Loading them tells the image's
server that the chat was opened, and a reply could put chat contents in the image address.

## Artifacts in a side panel

On by default. When a reply makes an [artifact](../using/chats.html#artifacts) (a web page,
drawing or long code), the panel opens beside the chat. When off, open it with **Open in panel**
by its link in the reply, or the panel button at the top right. How web pages show in the panel
is under [General → Web page preview](general.html#web-page-preview).
